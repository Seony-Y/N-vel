# N-vel 기획: AI 추리 게임

AI 용의자를 심문하고 단서를 모아 범인을 지목하는 추리 게임. 사건을 직접 만들어 공유할 수도 있고, 사이트가 공식 사건을 제공한다.

## 결정 사항 (2026-10-22)

- 혼자 플레이 먼저. 여러 명 플레이는 나중에
- 입력: 자유 입력 + 버튼 혼합 (장소 이동·증거 제시는 버튼, 행동·질문은 자유 입력)
- 기존 캐릭터 채팅 기능은 완전히 대체. 로그인·DB·AI 연결·사용량 기록·캐싱·테스트 응답 모드·HTML 샌드박스는 재사용
- 등급: 범죄·살인 묘사는 15세 자율 표시 + 경고 태그. 실제로 따라 할 수 있는 범죄 방법은 다루지 않음
- "크라임씬" 은 방송 이름이므로 서비스 이름으로 쓰지 않음

## 핵심 원칙: 진실은 데이터가 정한다

| 담당 | 역할 |
|---|---|
| 데이터 (제작자) | 진상, 범인, 타임라인, 단서, 용의자별로 아는 것·숨기는 것 |
| 서버 | 단서 공개 조건 판정, 진행 상태, 채점. 정답은 화면에 보내지 않음 |
| AI | 용의자 연기, 장면 묘사, 단서 공개를 서버에 "요청" (tool use) |

- 용의자마다 AI 에게 주는 정보를 분리한다. 범인이 아닌 용의자의 프롬프트에는 진상이 없다.
- 상태 변경(단서 발견, 거짓말 붕괴)은 AI 의 자유 텍스트가 아니라 도구 호출로 받고, 서버가 조건을 검증한다.

## 사건 구조

```
사건
 ├─ 개요: 제목, 등급, 난이도, 예상 시간, 도입부(HTML 가능)
 ├─ 진상(비공개): 범인, 동기, 수단, 실제 타임라인
 ├─ 장소
 ├─ 단서: 위치(장소/용의자), 발견 조건(장소 조사, 선행 단서, 비밀번호), 내용(텍스트/이미지/HTML 문서)
 ├─ 용의자: 공개 정보, 주장하는 알리바이, 실제 행적, 비밀, 거짓말, 무너지는 조건(특정 증거 제시)
 └─ 엔딩: 정답 / 부분 정답 / 오답
```

## 플레이

- 조사: 장소 선택 → 행동 입력 → AI 묘사, 조건 맞으면 단서 발견
- 심문: 용의자와 대화, 증거 제시로 반응 변화
- 수첩: 단서·진술 자동 정리 + 메모
- 방탈출: 비밀번호 잠금, 단서 조합
- 제한(선택): 행동 횟수/시간, 힌트는 점수 차감
- 추리 제출: 범인·동기·수단·결정적 증거 → 채점 → 엔딩

## 단계

1. MVP: 혼자 플레이, 공식 예시 사건 1개, 조사·심문·증거 제시·수첩·추리 제출
2. 제작: 사건 에디터, AI 검수(해결 가능성·모순 확인), 공개·공유, 등급·경고 태그
3. 게임성: 잠금, 단서 조합, 힌트, 점수·랭킹
4. 확장: 여러 명 플레이, AI 사건 초안 생성
